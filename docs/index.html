About the classifications
How this works: records are crawled directly from each journal's Harvard Dataverse collection. Method and data-type tags are generated by automated keyword matching against each dataset's title, abstract, and author-supplied keywords. A classifier will miss paraphrased methods and can over-match on common words. Use the tags to narrow a search, but verify by reading the abstract or the linked dataset.
Not indexed here: Journal of Conflict Resolution and Journal of Peace Research don't publish to a dedicated Harvard Dataverse collection, so they can't be crawled or searched on this page. Their replication data is linked per-article from JCR's table of contents and via PRIO's dataset page for JPR.

Full methodology in the repository README. Data refreshed monthly. MIT licensed.
