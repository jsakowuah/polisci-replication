Political Science Replication Index

A searchable index of replication packages from six flagship political science journals' Harvard Dataverse collections, tagged by method and data type.

How this works: records are crawled directly from each journal's Harvard Dataverse collection. Method and data-type tags are generated by automated keyword matching against each dataset's title, abstract, and author-supplied keywords — tags are a search aid, not ground truth. A classifier will miss paraphrased methods and can over-match on common words. Use the tags to narrow a search, but verify by reading the abstract or the linked dataset.
